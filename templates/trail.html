Every action, newest first. The database refuses edits and deletes on this log, and each row stores a hash of the row before it. On every load the page re-checks the chain and replays the log against the working tables, so a direct edit to the database shows up here. Someone with full database access could still rebuild the whole chain; the next step would be to send the latest hash outside the database each day.
